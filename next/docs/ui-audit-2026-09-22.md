### A.5 The canonical screen (what most screens do)

Counts are over routed feature templates.

1. **Wrapper:** `<div class="page">` (35 files).
2. **Header:** `.page-head` → left `<h1 class="page-title">` + `<p class="page-subtitle">`; right a `flex items-center gap-2` action group: `btn btn-default btn-sm` **Refresh** with `<app-icon name="refresh" [class.spin]="loading()">` and `[disabled]="loading()"`, then secondary `btn-default btn-sm`, then one `btn btn-primary btn-sm` "New …" with `plus` icon (28 files use `.page-head`, 34 `.page-title`). Reference: `features/tasks/tasks.html:1-22`.
3. **KPI row (optional):** grid of `app-stat-tile` (18 files).
4. **List:** `app-table-shell` with `heading`, `[loading]`, `[error]`, `[isEmpty]`, `[shown]`/`[total]`, contextual `emptyMessage` ("No X match your search." vs "No X yet."), `emptyIcon`, `(retry)="load()"`.
   - Toolbar slot order: `app-view-toggle` → filter `app-combobox`/`select.input` → `.search-field` (`app-icon search` + `input.input`, `max-w-56`) → `app-mine-filter` → conditional ghost **Clear** button with `close` icon.
   - Table: `<table class="table-modern">`, sortable headers `<button class="th-sort">` via `createSort()`, row actions in a kebab `btn btn-ghost btn-icon btn-sm` with `aria-label="Actions"` opening a `cdkMenu` of `.menu-item`s, destructive last with `btn-intent-crit`/`menu-item-danger`.
   - Cards view: `grid gap-3 p-4 sm:grid-cols-2 xl:grid-cols-3` of `article.card p-4`.
   - Pager: `<app-pagination pager …>` fed by `createPager()`.
5. **States:** loading = table-shell spinner, then blur-loader on refresh; error = table-shell error block with Try again; empty = icon + message (+ optional `empty-action`). Non-list pages use `.spinner` + text or `app-blur-loader`.
6. **Forms:** create/edit in `app-form-dialog` (13 files) or full-page edit (`job-edit`, `task-edit`, `prompt-edit`) using `app-field` + `.form-grid` + `.form-section` + `.form-actions`; validation errors inline through `app-field`; server errors as `toast.error`.
7. **Destructive actions:** `confirmWith(dialog, { title, body, confirmLabel: 'Delete …', danger: true })` (26 files, 31 calls; 27 set `danger`). Reversible "turn off" actions (Deactivate user, Suspend tenant) use `danger: true` too.
8. **Toasts:** success after every mutation (`"<name> deleted."`), `toast.error(response.message || 'Could not …')` on failure.
9. **Icons:** `app-icon` only; exactly one raw `<svg>` in features (`reports/report-chart.ts:84`, a chart).
10. **Search placeholders:** two dialects — older list screens use `"Search id, name …"` without `aria-label` (15 inputs); newer screens use `"Find a …"` **with** `aria-label` (14 inputs). The newer dialect is the accessible one.
