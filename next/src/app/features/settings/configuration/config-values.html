Configuration values

Values and secrets a task's payload reads at run time, per workspace — a bucket name, a database password — kept here once instead of written into every task.

A task references an entry by name inside its payload: {{ configRef }} for a value, {{ secretRef }} for a secret. The worker asks for the real value when the run starts; the payload, the queue message and the logs only ever carry the reference.

A tag whose name looks like a credential — password, secret, token, API key, access key, private key, client secret — must hold exactly {{ secretRef }}. A task that writes a literal there, or names a key that does not exist in its workspace, is refused when it is saved.
