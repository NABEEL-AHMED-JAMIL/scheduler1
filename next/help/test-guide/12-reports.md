These checks follow a report from its template to a signed PDF: publishing a template, generating a report, generating
it again, approving and signing it, checking the signature, and the guards around it. Whoever generated a version never
approves it, and nothing is overwritten: each generation is a new version.

**Before you start:** a brand profile with a logo and a signature approved in **Assets & branding** (or the workspace's
own), and a starter template. A2 or R must hold **Approve and sign reports**. Use synthetic data only.

## Limits and pipelines
| # | Check | Steps | Expected | Pass / Fail |
|---|---|---|---|---|
| QA-12.17 | The page limit | As A, **Reports › Settings** › **Most pages in one report**: lower it to `2`, **Save**; create a report whose data lays out to more pages | The report is not made: the message says how many pages it lays out to and the limit, and offers the ways out (one report per row, fewer table rows, export as CSV). Put the limit back (300 by default; only the platform administrator raises it further) | ☐ Pass ☐ Fail |
| QA-12.18 | A field missing from the data | Create a report from data that lacks a field the template uses | The message names the field: it is *not in this data*, with what to do (map it, change the binding, or mark it optional) | ☐ Pass ☐ Fail |
| QA-12.19 | A report from a pipeline | Add **Generate report** to `QA occupancy` with **Use a saved template** `QA summary`; **Save**; **Run now** | The run's **Outputs** hold the PDF; the report is a version in **Reports › Library**, approved there like any other | ☐ Pass ☐ Fail |
| QA-12.20 | The checks refuse, and the run goes on | Set **When the checks refuse it** to `CONTINUE_WITH_WARNING`; give the step data that fails a check; run | The step completes with no report and a warning on the run | ☐ Pass ☐ Fail |
| QA-12.21 | Retention is previewed, not run | As A, **Reports › Settings** › **What retention would remove**: **Older than (days)** `365`; **Preview** | It lists the files of versions a newer one replaced and frozen data no kept version uses; nothing is removed here; each report's current version and every approved or signed version stay | ☐ Pass ☐ Fail |

## The approver's own signature
| # | Check | Steps | Expected | Pass / Fail |
|---|---|---|---|---|
| QA-12.26 | The template waits for the approver | As A, in a draft of `QA summary`, add **Approver's signature** from **Approval**; publish; generate **v1** | The designer's box reads **Approver's signature**; v1's PDF shows an empty dashed box, **Awaiting approval**, where it goes | ☐ Pass ☐ Fail |
| QA-12.27 | Each approver's own signature | Make sure A2 and R each have an approved signature in **Assets & branding** that **Belongs to** them, with a **Title**; generate two reports from `QA summary`; A2 approves one, R the other | Each PDF shows its approver's own signature, name, title and the time of approval, never the other's; the report's page lists them under **Signature on it** | ☐ Pass ☐ Fail |
| QA-12.28 | No signature of their own | An approver with no approved signature (or retire theirs first) approves a new version | The PDF shows their typed name and **SIGNED DIGITALLY**, no picture; **Signature on it** says *typed name, signed digitally* | ☐ Pass ☐ Fail |
| QA-12.29 | The check warns about a fixed signature | In a draft, put a **Signature (fixed person)** in the same section as a **Label and value** labelled `Reviewed by` | The checks warn *One person's signature beside an approval* on that signature and name **Approver's signature**; it is a warning, publishing still works | ☐ Pass ☐ Fail |
| QA-12.30 | An approved version stays as approved | After QA-12.27, upload a new version of A2's signature and approve it; download the version A2 approved earlier | The earlier PDF is unchanged (Verify signature still holds) and shows the old signature; A2's next approval shows the new one | ☐ Pass ☐ Fail |

|---|---|---|---|---|

## Example
At Summit Valley the Summit Valley admin generates Elena Marsh's discharge summary; the page tells him *You generated it;
someone else approves it.* Dr. Minh Nguyen chooses **Approve and sign**, and **Verify signature** on the PDF confirms it
is intact and one of the workspace's approved reports.
