Forms collect the same answers the same way every time: an admission, a triage, an expense claim. A workspace
administrator builds them from twelve field types with logic that shows or requires a field only when it applies;
members fill them in, signed in. Each submission is kept, and can start a pipeline, an approval workflow, or both.

## Questions
### Who can fill in our forms?
Signed-in members of the workspace whose page access includes **Forms**, and only **Active** forms. Links for anyone
else are off until an administrator turns them on. See [Share a form](#form-share).

### Why can't I find the New form button?
Building forms is a workspace administrator's. Others see the Active forms to fill in. See [Build a form](#form-build).

### Can a question appear only when it applies?
Yes: on the **Logic** tab, **Show only when** or **Also required when** an earlier answer says so. See
[Show or require a field when](#form-logic).

### My submission says "Run not started". Why?
The form's pipeline could not start; **Details** on its row says why. See [Submissions](#form-submissions).

### Where do attached files and signatures go?
They are kept with the submission and listed with its answers. A file can also be sent to Document Intelligence to be
read. See [Submissions](#form-submissions--read-a-submission).

### Analytics is missing some of a form's submissions. What can I do?
An administrator can choose **Rebuild dataset files** in the form's row menu; no answer changes. See
[The form's dataset and Rebuild dataset files](#form-dataset).
