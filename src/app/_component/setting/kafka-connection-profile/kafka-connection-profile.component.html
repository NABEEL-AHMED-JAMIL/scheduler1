A password is already configured -- only fill this in to replace it.
Copy the username/password straight from your Kafka provider's console (e.g. Aiven's "Service users" tab, Confluent Cloud API keys, or your own SASL/SCRAM user setup). The mechanism must match what the provider issued the credentials for -- PLAIN for a plain username/password pair, SCRAM-SHA-256/SCRAM-SHA-512 if the provider explicitly created a SCRAM user. Using the wrong mechanism fails auth even with the right password. The password is AES-encrypted at rest and never shown again once saved.
Kafka needs a PKCS12 truststore/keystore, not raw PEM files. If your provider gave you PEM certs (ca.pem, service.cert, service.key), convert them first:
Truststore (always required for SSL/SASL_SSL):
keytool -importcert -alias ca -file ca.pem -keystore truststore.p12 -storetype PKCS12 -storepass YOUR_PASSWORD -noprompt
Keystore (only for mTLS / client-certificate auth):
openssl pkcs12 -export -in service.cert -inkey service.key -certfile ca.pem -out keystore.p12 -passout pass:YOUR_PASSWORD
⚠ Don't skip -certfile ca.pem on the keystore export -- omitting it causes a "TLS handshake failed" error even though the cert/key pair itself is valid.
